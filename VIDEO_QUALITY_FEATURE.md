# Выбор качества YouTube видео

## Что добавлено

В видеоплейер добавлена **кнопка выбора качества** для YouTube видео. Теперь можно вручную выбирать разрешение видео.

## Как использовать

### 1. Доступность
- ✅ Кнопка появляется **только для YouTube видео**
- ✅ Доступна **всем пользователям** (не только модератору)
- ✅ Расположена в контрол-баре между регулятором громкости и полноэкранным режимом

### 2. Как выбрать качество

1. Откройте комнату с YouTube видео
2. В контрол-баре плейера найдите кнопку **HD** (иконка качества)
3. Нажмите на кнопку
4. Откроется меню с доступными качествами:
   - 4K (2160p)
   - 1440p
   - 1080p
   - 720p
   - 480p
   - 360p
   - 240p
   - 144p
   - Авто

5. Выберите желаемое качество
6. Видео переключится на выбранное качество
7. Текущее качество отмечено галочкой ✓

### 3. Особенности

**Доступные качества зависят от видео:**
- Не все видео имеют все разрешения
- Список качеств загружается автоматически после загрузки видео
- Если качество недоступно, оно не отобразится в списке

**Автоматическое сохранение позиции:**
- При переключении качества позиция воспроизведения сохраняется
- Статус воспроизведения (пауза/воспроизведение) также сохраняется

**Синхронизация:**
- Выбор качества локальный (каждый пользователь выбирает свое)
- Не влияет на других участников комнаты
- Полезно для пользователей с разной скоростью интернета

## Технические детали

### Реализация

**Компонент:** `VideoPlayer.tsx`
**Технологии:**
- video.js с YouTube плагином (videojs-youtube)
- YouTube IFrame Player API
- Material-UI Menu для интерфейса выбора

**Ключевые функции:**
```typescript
// Получение доступных качеств
getYouTubeQualities()
  → Использует ytPlayer.getAvailableQualityLevels()

// Переключение качества
changeYouTubeQuality(quality: string)
  → Использует ytPlayer.setPlaybackQuality(quality)
  → Сохраняет currentTime и состояние паузы
```

### Качества YouTube

YouTube использует следующие обозначения:
- `highres` = 4K (2160p) - оригинальное качество
- `hd1440` = 1440p - QHD
- `hd1080` = 1080p - Full HD
- `hd720` = 720p - HD
- `large` = 480p - стандартное
- `medium` = 360p
- `small` = 240p
- `tiny` = 144p
- `auto` = автоматический выбор YouTube

### Работа с API

**YouTube IFrame Player API методы:**
```javascript
// Получить доступные качества
ytPlayer.getAvailableQualityLevels()
// Возвращает: ['hd1080', 'hd720', 'large', 'medium', 'small']

// Получить текущее качество
ytPlayer.getPlaybackQuality()
// Возвращает: 'hd720'

// Установить качество
ytPlayer.setPlaybackQuality('hd1080')
```

## Для локальных видео (не YouTube)

Для видео загруженных на сервер (не YouTube), выбор качества **не доступен**, так как:
- Локальные файлы имеют одно фиксированное разрешение
- Нет множества версий одного видео
- Переключение потребовало бы загрузки другого файла

## Стилизация

**Файлы стилей:**
- `VideoPlayer.css` - кастомные стили для кнопки качества
- Использует встроенные иконки VideoJS

**Внешний вид:**
- Иконка HD в контрол-баре
- При наведении - подсветка
- Tooltip с надписью "Качество видео"

## Известные ограничения

1. **Доступность качеств**
   - Зависит от оригинального видео на YouTube
   - Старые/короткие видео могут иметь меньше вариантов

2. **Задержка переключения**
   - Может быть небольшая задержка при смене качества
   - YouTube буферизует новый поток

3. **Только для YouTube**
   - Не работает для Vimeo, прямых ссылок или локальных файлов
   - Кнопка автоматически скрывается для не-YouTube контента

4. **Синхронизация между пользователями**
   - Качество не синхронизируется между участниками
   - Каждый выбирает свое независимо

## Рекомендации

**Для пользователей с медленным интернетом:**
- Выберите 360p или 480p для стабильного воспроизведения
- Избегайте 1080p/4K без хорошего соединения

**Для лучшего качества:**
- Выберите максимальное доступное разрешение
- Убедитесь в стабильном интернете (10+ Mbps для 1080p)

**Рекомендуемые настройки:**
- **Низкая скорость (<2 Mbps):** 240p - 360p
- **Средняя скорость (2-5 Mbps):** 480p - 720p
- **Высокая скорость (5-10 Mbps):** 720p - 1080p
- **Очень высокая (>25 Mbps):** 1440p - 4K

## Troubleshooting

**Кнопка качества не появляется:**
- Убедитесь, что воспроизводится YouTube видео
- Подождите загрузки метаданных видео (~1 секунда)
- Проверьте консоль браузера (F12) на ошибки

**Список качеств пуст:**
- YouTube API может быть недоступен
- Проверьте интернет-соединение
- Попробуйте перезагрузить страницу

**Качество не переключается:**
- Некоторые качества могут быть недоступны временно
- Попробуйте другое качество
- YouTube может ограничивать доступ к высоким разрешениям

**Видео зависает после переключения:**
- Нормально для медленного интернета
- YouTube буферизует новый поток
- Подождите несколько секунд
