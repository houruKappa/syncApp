# YouTube Поиск - Краткая инструкция

## Что добавлено

Теперь в приложении есть **встроенный поиск YouTube видео** прямо в интерфейсе очереди!

## Как использовать

### Быстрый старт (без API ключа)

Без API ключа можно использовать другие методы добавления видео:
- ✅ **URL видео** - вставьте ссылку на YouTube (работает без ключа)
- ✅ **Загрузка с ПК** - загрузите свой файл

### С YouTube поиском (нужен API ключ)

1. **Получите YouTube API ключ** (5 минут)
   - Следуйте инструкции в файле `YOUTUBE_API_SETUP.md`
   - Короткая версия:
     - Откройте https://console.cloud.google.com/
     - Создайте проект
     - Включите YouTube Data API v3
     - Создайте API ключ
     - Добавьте в `frontend/.env`: `REACT_APP_YOUTUBE_API_KEY=ваш_ключ`

2. **Перезапустите фронтенд**
   ```bash
   docker-compose restart frontend
   ```

3. **Используйте поиск**
   - Откройте любую комнату
   - Нажмите "Добавить" в очереди видео
   - Выберите вкладку **"Поиск YouTube"**
   - Введите запрос (например: "lofi music")
   - Выберите видео из результатов
   - Видео автоматически добавится в очередь!

## Возможности YouTube поиска

✨ **Что вы увидите:**
- 🖼️ Превью видео (thumbnail)
- ⏱️ Длительность видео
- 📝 Название видео
- 👤 Канал автора
- 📅 Дата публикации

✨ **Преимущества:**
- Не нужно открывать YouTube отдельно
- Видео добавляется одним кликом
- Все метаданные заполняются автоматически
- Поддерживается кириллица в поиске

## Три способа добавить видео

### 1️⃣ Поиск YouTube (новое!)
- Удобный поиск с превью
- Требует API ключ
- Лучший UX

### 2️⃣ URL видео
- Вставьте любую ссылку
- YouTube, Vimeo, прямые ссылки
- Работает всегда

### 3️⃣ Загрузка с ПК
- Загрузите MP4, WebM, OGG
- До 200MB
- Хранится на сервере

## Ограничения

**YouTube API квота: 10,000 единиц/день**
- ~90 поисковых запросов в день
- Этого достаточно для личного использования
- Можно запросить увеличение (обычно дают бесплатно)

## Для разработчиков

**Новые файлы:**
- `frontend/src/components/YouTubeSearch.tsx` - компонент поиска
- `frontend/.env` - конфигурация (добавить API ключ)
- `YOUTUBE_API_SETUP.md` - документация по настройке
- `YOUTUBE_QUICK_START.md` - этот файл

**Изменённые файлы:**
- `frontend/src/components/VideoQueue.tsx` - добавлена вкладка поиска
- `frontend/.env.example` - добавлен параметр API ключа

**Технические детали:**
- YouTube Data API v3
- Поиск: `search.list` (100 units)
- Детали: `videos.list` (1 unit per video)
- Material-UI компоненты
- Axios для HTTP запросов
- Форматирование ISO 8601 duration
